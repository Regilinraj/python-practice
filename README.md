# Python Practice

small python programs I wrote while practising for entry-level developer roles.

## what it does

'salary.py' takes a list of employee salary and prints:
- total salary
- highest salary
- average salary
- how many salaries above 30000

## How to run

1. Install Python
2. Open terminal in this folder
3. Run:python salary.py

## sample output
```
total: 160000
max: 45000
average: 32000.0
above 30000: 2
```
